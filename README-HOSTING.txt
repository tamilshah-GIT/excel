Excelok Technologies website package
====================================
Upload the contents of this folder to your web hosting public root.
Entry point: index.html
Static routes are provided as folders with index.html files.
Forms are front-end ready and show success states; connect them to Resend, SendGrid, CRM or your hosting form endpoint for live email delivery.
The RFQ cart, search, language switcher, gallery lightbox, cookie notice and chat panel run in browser JavaScript.
Public source assets included: Excelok product images and brochure, plus ATEC reference marine imagery/icons fetched from the provided websites.
